# InFlow в SpringPlusCosmetics (Fabric 26.2)

В beta.208 интерфейс Cosmetics напрямую подключён к публичному API вложенного InFlow1.0.48. Отдельный Windows Client не требуется.

## Открытие

- В заголовке меню SpringPlus: компактный щит слева открывает панель; колесо справа убрано, чтобы не перекрывать крестик.
- В игровом чате и меню паузы плавающие кнопки скрыты; панель доступна через щит в меню SpringPlus или горячие клавиши.
- F9 — колесо, F10 — панель. Клавиши переназначаются в настройках управления Minecraft.
- Через панель доступны карточки и дела, проверки, журнал, жалобы, доказательства, модераторские профили и остальные возможности общего модуля. Превью и выбор анимаций остаются в колесе.

Кнопки видны только при разрешённом доступе и повторно проверяют его при нажатии. Отзыв прав/смена соединения учитываются общим модулем. Скрытые кнопки не участвуют в фокусе и обработке клавиш чата. На слишком маленьком окне кнопки скрываются, а не перекрывают содержимое. Горячие клавиши и обработчики пакетов регистрирует только InFlow, не адаптер Cosmetics.

## Совместимость

Нужны Java25, Minecraft26.2, Fabric Loader>=0.19.3, Fabric API>=0.156.0+26.2 и серверный адаптер InFlow с соответствующими правами. Этот патч не меняет серверные команды, идентификаторы каналов и выдачу прав.

Старые Windows Client<1.0.48 несовместимы с вложенным ядром. Для совместного запуска использовать Windows Client1.0.48 с тем же InFlow1.0.48; иначе запускать Cosmetics без Windows Client. Не добавлять отдельную старую копию InFlow рядом.

NeoForge в этом патче не получает InFlow: его номер beta синхронизирован с релизом, но перенос сетевого/событийного адаптера остаётся отдельной задачей.

## Проверки

Из каталога FemaleGenderMod:

```powershell
.\gradlew.bat :26.2:build :26.2:checkInFlowHost :26.2:checkSharedLoaderParity :26.2:checkPublicChat :26.2:checkChatMotion -I tests/uv-check.gradle
```

Из корня репозитория:

```powershell
.\inflow\gradlew.bat -p inflow :client:build
java inflow/verification/VerifyIntegration.java .
```

На локальной сборке эти проверки прошли. Также проверено совпадение вложенной InFlow JAR с Windows Client1.0.48. Это не заменяет проверку в игре: отдельно проверить обычного игрока, модератора с LP без OP, смену сервера, открытие из всех трёх экранов и работу с установленным серверным плагином. Рабочая сборка автоматически не заменяется.
